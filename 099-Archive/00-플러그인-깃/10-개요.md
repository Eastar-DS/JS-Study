# **Obsidian Git 플러그인**

Git 연동을 볼트 안으로 바로 가져오는 Obsidian.md용 강력한 커뮤니티 플러그인입니다. Obsidian 안에서 자동으로 commit, pull, push하고 변경 사항을 확인할 수 있습니다.

## **📚 문서**

모든 설정 지침(모바일 포함), 일반적인 문제, 팁, 고급 설정은 📖 [전체 문서](https://publish.obsidian.md/git-doc)에서 찾을 수 있습니다.

> 모바일 사용자: 이 플러그인은 **매우 불안정합니다 ⚠️ !** 아래의 전용 Mobile 섹션을 확인하세요.
> 

## **주요 기능**

- 🔁 일정에 따른 **자동 commit-and-sync**(commit, pull, push).
- 📥 **Obsidian 시작 시 자동 pull**
- 📂 여러 저장소를 관리하기 위한 **서브모듈 지원**(데스크톱 전용 및 opt-in)
- 🔧 파일을 stage/unstage하고 commit 및 diff할 수 있는 **Source Control View** - `Open source control view` 명령으로 엽니다.
- 📜 커밋 로그와 변경된 파일을 탐색하는 **History View** - `Open history view` 명령으로 엽니다.
- 🔍 파일의 변경 사항을 보는 **Diff View** - `Open diff view` 명령으로 엽니다.
- 📝 추가, 수정, 삭제된 줄/hunk를 나타내는 **편집기 내 표시(Signs)**(데스크톱 전용).
- 브라우저에서 파일과 히스토리를 여는 GitHub 연동

> 자세한 파일 히스토리를 보려면 이 플러그인을 Version History Diff 플러그인과 함께 사용하는 것을 고려하세요.
> 

## **UI 미리보기**

### **🔧 Source Control View**

개별 파일을 stage/unstage하고 commit하는 것처럼, Obsidian 안에서 파일 변경 사항을 직접 관리합니다.

![Source Control View](https://raw.githubusercontent.com/Vinzent03/obsidian-git/master/images/source-view.png)

### **📜 History View**

저장소의 커밋 히스토리를 보여줍니다. 커밋 메시지, 작성자, 날짜, 변경된 파일을 표시할 수 있습니다. 스크린샷에 보이는 것처럼 작성자와 날짜는 기본적으로 비활성화되어 있지만 설정에서 활성화할 수 있습니다.

![History View](https://raw.githubusercontent.com/Vinzent03/obsidian-git/master/images/history-view.png)

### **🔍 Diff View**

명확하고 간결한 diff 뷰어로 버전을 비교합니다.

source control view에서 열거나 `Open diff view` 명령을 통해 엽니다.

![Diff View](https://raw.githubusercontent.com/Vinzent03/obsidian-git/master/images/diff-view.png)

### **📝 편집기 내 표시(Signs)**

추가, 수정, 삭제된 줄/hunk 표시를 통해 편집기에서 줄 단위 변경 사항을 직접 볼 수 있습니다. 표시에서 바로 변경 사항을 stage하고 reset할 수 있습니다. hunk 사이를 이동하고 커서 아래의 hunk를 stage/reset하는 명령도 있습니다. 플러그인 설정에서 활성화해야 합니다.

![Signs](https://raw.githubusercontent.com/Vinzent03/obsidian-git/master/images/signs.png)

## **사용 가능한 명령**

> 전체 목록은 아닙니다. 가장 일반적인 명령 중 일부일 뿐입니다. 전체 목록은 Obsidian의 Command Palette를 보세요.
> 
- 🔄 변경 사항
    - `List changed files`: 모든 변경 사항을 모달에 나열합니다.
    - `Open diff view`: 현재 파일의 diff view를 엽니다.
    - `Stage current file`
    - `Unstage current file`
    - `Discard all changes`: 저장소의 모든 변경 사항을 폐기합니다.
- ✅ Commit
    - `Commit`: 파일이 staged 상태라면 해당 파일만 커밋하고, 그렇지 않으면 staged 상태인 파일만 커밋합니다.
    - `Commit with specific message`: 위와 같지만 사용자 지정 메시지를 사용합니다.
    - `Commit all changes`: push하지 않고 모든 변경 사항을 커밋합니다.
    - `Commit all changes with specific message`: 위와 같지만 사용자 지정 메시지를 사용합니다.
- 🔀 Commit-and-sync
    - `Commit-and-sync`: 기본 설정에서는 모든 변경 사항을 커밋하고, pull하고, push합니다.
    - `Commit-and-sync with specific message`: 위와 같지만 사용자 지정 메시지를 사용합니다.
    - `Commit-and-sync and close`: `Commit-and-sync`와 같지만, 데스크톱에서 실행 중이면 Obsidian 창을 닫습니다. 모바일에서는 Obsidian 앱을 종료하지 않습니다.
- 🌐 원격(Remote)
    - `Push`, `Pull`
    - `Edit remotes`: 새 remote를 추가하거나 기존 remote를 편집합니다.
    - `Remove remote`
    - `Clone an existing remote repo`: 원격 저장소를 클론하기 위한 URL과 인증을 요청하는 대화상자를 엽니다.
    - `Open file on GitHub`: 현재 파일의 GitHub 파일 보기를 브라우저 창에서 엽니다. 참고: 데스크톱에서만 작동합니다.
    - `Open file history on GitHub`: 현재 파일의 GitHub 파일 히스토리를 브라우저 창에서 엽니다. 참고: 데스크톱에서만 작동합니다.
- 🏠 로컬 저장소 관리
    - `Initialize a new repo`
    - `Create new branch`
    - `Delete branch`
    - `CAUTION: Delete repository`
- 🧪 기타
    - `Open source control view`: Source control view를 표시하는 사이드 패널을 엽니다.
    - `Open history view`: History view를 표시하는 사이드 패널을 엽니다.
    - `Edit .gitignore`
    - `Add file to .gitignore`: 현재 파일을 `.gitignore`에 추가합니다.

## **💻 데스크톱 참고 사항**

### **🔐 인증**

일부 Git 서비스는 HTTPS/SSH 인증을 위해 추가 설정이 필요할 수 있습니다. [인증 가이드](https://publish.obsidian.md/git-doc/Authentication)를 참고하세요.

### **Linux의 Obsidian**

- ⚠️ Snap은 샌드박스 제한 때문에 지원되지 않습니다.
- ⚠️ Flatpak은 모든 시스템 파일에 접근할 수 없기 때문에 권장되지 않습니다. 많은 문제를 적극적으로 수정하고 있지만 여전히 문제가 있습니다. 특히 더 고급 설정에서 그렇습니다.
- ✅ 대신 AppImage 또는 시스템 패키지 관리자의 전체 접근 설치를 사용하세요([Linux 설치 가이드](https://publish.obsidian.md/git-doc/Installation#Linux)).

## **📱 모바일 지원(⚠️ 실험적)**

모바일의 Git 구현은 **매우 불안정합니다**! 모바일에서 이 플러그인을 사용하는 것은 권장하지 않으며, 다른 동기화 서비스를 시도해보는 것을 권합니다.

그러한 대안 중 하나는 Android와 iOS 모두에서 사용할 수 있는 [GitSync](https://github.com/ViscousPot/GitSync)입니다. 이 플러그인과 관련은 없지만 모바일 사용자에게 더 나은 선택지일 수 있습니다. 설정 튜토리얼은 [여기](https://viscouspotenti.al/posts/gitsync-all-devices-tutorial)에서 찾을 수 있습니다.

> 🧪 Git 플러그인은 JavaScript 기반 Git 재구현인 [isomorphic-git](https://isomorphic-git.org/) 덕분에 모바일에서 작동합니다. 하지만 심각한 제한과 문제가 따릅니다. Obsidian 플러그인이 Android나 iOS에서 네이티브 Git 설치를 사용하는 것은 불가능합니다.
> 

### **❌ 모바일 기능 제한**

- **SSH 인증** 없음([isomorphic-git issue](https://github.com/isomorphic-git/isomorphic-git/issues/231))
- 메모리 제한으로 인해 저장소 크기 제한
- rebase 병합 전략 없음
- 서브모듈 지원 없음

### **⚠️ 성능 주의 사항**

**주의**

기기와 사용 가능한 여유 RAM에 따라 Obsidian은 다음과 같은 문제가 생길 수 있습니다.

- clone/pull 중 충돌
- 버퍼 오버플로 오류 생성
- 무기한 실행

이는 모바일의 기반 git 구현이 효율적이지 않기 때문에 발생합니다. 저는 이 문제를 해결하는 방법을 모릅니다. 여러분에게 이런 상황이 해당된다면, 이 플러그인은 여러분에게 작동하지 않을 것임을 인정해야 합니다. 따라서 어떤 이슈에 댓글을 달거나 새 이슈를 만들어도 도움이 되지 않습니다. 죄송합니다.

### **모바일 사용 팁:**

큰 저장소/볼트가 있다면 개별 파일을 stage하고 staged 파일만 커밋하는 것을 권장합니다.
