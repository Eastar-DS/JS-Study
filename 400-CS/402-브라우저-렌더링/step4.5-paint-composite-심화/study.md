# 01 Stacking Context

## 정리
Stacking Context는 요소들이 z축 방향으로 어떤 순서로 쌓이고 그려질지 결정하는 독립적인 쌓임 영역입니다.



## 질문
1. Stacking Context는 무엇인가요?
=> 바로 떠오르는건 z-index. z축으로 어떻게 쌓을지 결정한 컨텍스트? 여러 레이어로 나누어서 각 레이어별로 뭐가 위치해야할지 결정하는 것 처럼 느껴졌음.
2. `z-index: 9999`가 항상 모든 요소 위로 올라가지 않는 이유는 무엇인가요?
=> 부모의 z-index가 다른요소의 z-index보다 작다면 아무리 나의 z-index가 커도 위에 안보일 수 있음.
3. Paint 단계에서 쌓임 순서를 이해해야 하는 이유는 무엇인가요?
=> 왜 내가 설정한게 가려지거나 안보이지? 같은 일이 발생했을 때 원인을 찾아볼 수 있음.
